1
模式一 · 首次初始化（一次性）
bash scripts/setup.sh —— 检测环境 → 装齐三件套 + 下游 skill → 写入路径快照，之后免检
① 探测环境
扫描本机
识别 OS / GPU / 显存 / 内存，定位当前 Agent 的标准 skills 目录
② 装三件套
FFmpeg · whisper.cpp · yt-dlp
已存在则跳过；预编译二进制优先，包管理器兜底，全程镜像加速
③ 选模型
按硬件自动选档
large-v3 / medium / small（中文优先），下载 ggml 模型
④ 装下游 skill
拉取 AI_Animation 合集
scholar-notes / ppt-animation / flowchart 装到标准 skills 目录；git clone 优先，失败 fallback zip + 镜像站
⑤ 写快照
env.local.json
记录工具路径 + 模型档位 + 参数 + 平台（只由 setup 生成，绝不手写）
就绪
重启 Agent · 进入日常模式
让新装的下游 skill 被发现，之后永久免检
2
模式二 · 日常使用 Pipeline
bash scripts/process.sh —— 双入口 → 缓存检查 → 转录（字幕优先）→ 带时间戳文稿入库
◆ Step 1 · 双入口判断 —— 用户给的是什么？
http(s):// 开头 → URL 模式
process.sh url · B站 / YouTube / yt-dlp 支持的任意平台
本地路径 → 本地模式
process.sh local · 视频或音频：面试录音 mp3/m4a、录屏 mp4、会议录音…跳过下载直接转录
◆ Step 2 · 缓存命中检查 —— library/<id>/ 里已有文稿吗？
✓ 命中
直接复用现有 transcript，秒出 → 跳至阶段 3 输出菜单
✗ 未命中
继续向下执行下载 / 转录流程 ↓
⚡ 同一视频二次使用：零下载 · 零转录 · 零等待
yt-dlp（仅 URL 模式）
下载视频
同时尝试 --write-subs 拉取官方字幕（zh-Hans / zh / en）
◆ 字幕优先判断 —— 有官方字幕吗？
✓ 有官方字幕
直接复制为 transcript.srt，零成本 · 100% 准确，跳过音频提取与 Whisper
✗ 无字幕（本地文件默认走这里）
fallback：先 FFmpeg 提音频，再 whisper.cpp 转录
⚡ 字幕直接生成 无需提音频、无需转录，秒得文稿
FFmpeg
提取音频轨
视频 → 16kHz 单声道 wav；音频文件直接进入下一步
whisper.cpp
本地转录（中文优先）
-l zh 输出 srt；GPU 可用时自动加速（15–28×）
结构化文稿
生成 transcript · 带时间戳
.srt（带时间戳）+ .txt（纯文本），按视频 ID（本地文件按内容 hash）归档
入库
写入 library/ 媒体库
打印 TRANSCRIPT_READY <路径>，后续所有输出共享这份文稿
