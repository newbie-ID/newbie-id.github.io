黑猩猩 会用工具、能规划、短期记忆优于人类 —— 智力上与人难分伯仲
人类 拥有 language → 得以沟通协作 → 称霸地球
语言的双重角色
语言不只用于 沟通（communication）。Manning 认为，它还支撑了人类 更高层次的思维与规划 —— 我们常常"用语言在脑中思考"。这就给了思维一个 scaffolding（脚手架）。
口语 ≈几十万年 vs 写作 ≈5,000 年
写作是极晚近的发明，却让知识得以跨时空共享——从青铜时代一路走到人手一台的手机。
Herb Clark（斯坦福心理学家）："语言的使用主要不在于词及其意义，而在于人及其意义。"
深度学习如何改变 NLP
对语言的处理研究从 1950s 就开始，但前 60 年成果有限。真正飞跃发生在最近十年——靠的是神经网络。
1950s 起步 ➞ 2014 神经机器翻译 ➞ 2016 Google 上线 ➞ 2019 GPT-2 ➞ ChatGPT / GPT-4
现代搜索引擎已变成"答案引擎"：retrieval NN 找段落 → 第二个 NN 重排序 → 第三个 reading NN 综合作答。2019 年 GPT-2 首次能流畅生成连贯文本（甚至知道 Cincinnati 在 Ohio、核材料归能源部管）。
斯坦福提出的 foundation models：把 LLM 的同款技术扩展到图像、声音、DNA/RNA、地震波等任意信号。
如何表示"词义"
传统方案的两条死胡同
传统语义学采用 denotational semantics（符号 signifier ↔ 所指 signified）。但落地到计算机时，老办法都有硬伤。
WordNet 人工编纂的同义词/上下位词库。缺陷：✗ 缺乏 nuance（"proficient"≠"good shot"）✗ 不完整、缺新词俚语 ✗ 全靠人工维护
one-hot 向量 每个词是词表中一个位置为 1 的长向量（如 motel / hotel）。任意两词点积为 0、彼此正交，完全没有"相似度"概念（localist representation）
共同痛点：这些表示里没有任何 天然的相似度。
破局：分布式语义（distributional semantics）
J.R. Firth, 1957：
"You shall know a word by the company it keeps."（可追溯至 Wittgenstein）
既然上下文定义词义，那就用词周围的上下文来学习它的表示。于是词从离散符号，变成一个 dense vector（稠密向量 / embedding）：常见维度 100 / 300，大模型可达 1000–2000。
✓ 相似的词 → 相似的向量 → 点积大。可视化（用 t-SNE 降维）能看到国家词、动词语义群各自聚成簇。
 Word2Vec 核心算法
Word2Vec 是什么
发表于2013 · Tomas Mikolov @ Google
它既非首个也非末个词向量方法，但胜在简单 + 训练快，一举引爆关注。Manning 把它当作神经表示的 "baby system" 来入门。
术语 corpus（语料，拉丁词根"body"） — 复数是 corpora，不是 corpi（第四变格中性名词）
区分 word type（词的类型，如 "star"）vs word token（该词的一次具体出现）
算法直觉：用上下文预测中心词
给定大语料，遍历每个位置：取一个 center word（中心词 c）和窗口内的 outside/context words（上下文 o，如左右各 m=2 个）。用两者向量的相似度去算"它们共现的概率"，再调整向量，让真正共现的概率尽量大。
遍历语料每个位置 ➞ 取 center c + 窗口 m 内 context o ➞ 用向量点积算 P(o|c) ➞ 最大化真实共现概率 ➞ 梯度更新向量
例如见到 banking，模型应让 crises 出现的概率高、而 skillet 的概率低。注意每个词有两套向量：当中心词时的 v，当上下文词时的 u（仅为简化数学）。
目标函数：average negative log-likelihood
概念上想最大化所有上下文词的似然；实操用三个小技巧把它改写：
1加负号：最大化 → 最小化（gradient descent 的由来）
2取 log：连乘 ∏ → 连加 Σ，数学更好处理
3除以 T：把总量变成"每个词的平均"负对数似然
# θ = 模型全部参数（即所有词向量），T = 语料词数，m = 窗口大小
J(θ) = − (1/T) · Σt=1..T Σ−m≤j≤m, j≠0 log P( wt+j | wt ; θ )
最小化 J  =  最大化上下文词的共现概率。
概率怎么算？—— Softmax 登场
模型唯一的参数 θ 就是这些词向量。P(o|c) 用点积构造，分三步走：
第 1 步u·v 点积
➞
第 2 步exp(·) 变正
➞
第 3 步归一化为概率
# 点积给出相似度(无界实数)；exp 保证为正；对全词表归一化得概率
P(o | c) = exp( uoT vc ) / Σw=1..V exp( uwT vc )
为啥叫 softmax？它像 max（放大最大者），又是 "soft" 的——仍给小项留一份概率，把一串实数整体变成概率分布（和为 1）。深度学习里"把 Rn 向量变成概率"几乎都靠它。
梯度下降：observed − expected
对 vc 求偏导：把 log 拆成"分子 − 分母"，分子项 log(exp) 抵消得 uo；分母项反复用 chain rule。最终收敛成一个极其优雅的形式：
# 对中心词向量求偏导（链式法则展开后）
∂ log P(o|c) / ∂ vc  =   uo − Σx=1..V P(x|c) · ux
# ↑ observed（实际观察到的上下文向量）
# ↑ expected（按当前模型加权的期望向量）
当 observed = expected 时导数为 0，到达最优。这正是 ML 中反复出现的 "观测 − 期望" 结构。算完 vc，再对 uo 同理求导即可。
✓好消息：实际工作中计算机会自动求导（autograd），你很少手算。
✓从随机向量 + 一堆文本出发，仅靠最小化这个目标，就能学到有用的语义表示 —— 这就是深度学习的"小奇迹"。
应用与课堂答疑
词向量能做什么 & 课堂 Q&A
相似词自动聚类（国家、动词语义群） 向量空间中的"方向"也携带语义 t-SNE 降维可视化高维空间
Q1 一词多义？ 当前阶段每个 word type 只学一个向量，相当于各义项的平均（如 "star" 同时靠近 nebula 与 celebrity）。contextual 表示留到后面讲。
Q2 维度怎么选？ 100 维起效，300 常用，超大模型已用 1000–2000 维。
Q3 向量值有界吗？ 本质无界；常用 regularization 让系数别太大，或做 length normalize。
Q4 可视化方法？ t-SNE（非线性）通常比 PCA 更适合神经表示。
 本讲一句话总结
Word2Vec 用一个极简的"自监督"思路——让词向量去预测它的上下文——配合 softmax + 梯度下降，从纯文本中自动学到稠密的语义表示。它既证明了 分布式表示 的威力，也为后续 transformer / LLM 的全部故事打下了地基。
