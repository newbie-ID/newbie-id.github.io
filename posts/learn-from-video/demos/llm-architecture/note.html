方法论：用"调查"视角读所有论文
架构很难先验推理，最好的办法是 通读所有现代 LLM 论文（Qwen、Gemma、InternLM、LLaMA、Grok、Olmo、PaLM、T5…），看哪些选择在所有有效模型里固定、哪些可变。
转折点：LLaMA 2 发布后大家争相仿制，今年又涌现 Qwen3、Gemma4 等近 20 个新模型
架构本质是 表达力 ↔ 系统效率 ↔ 训练稳定性 的复杂权衡
Layer Norm 放置：唯一公认原版"没做对"的
Post-norm 原版 Transformer：归一化在残差流内。随深度增加出现梯度衰减/尖峰，需 warmup。OPT-350M 是反面例外
Pre-norm 归一化放残差流外、计算前。残差流"干净"，梯度直通传播，更稳、可去 warmup → 现代标配
黄金法则：一有稳定性问题 → 到处加 Layer Norm
近期变体：Grok / Gemma2 / Olmo2 用"后归一化但在残差流外"（双重 norm）。
RMSNorm 取代 LayerNorm + 去偏置
RMSNorm 只缩放（不减均值、不加偏置），表达力几乎无损但更快。关键在算术强度：
LayerNorm 只占 0.17% FLOPs，却可能占 25% 运行时间——它是内存搬运密集型，FLOPs ≠ 运行时间
移除线性层 bias：内存密集、可能引稳定性问题 → 全部移除，免费系统胜利
激活函数：门控线性单元（GLU）是标配
X × W₁ → ReLU × X·V (门控) → W₂ 下投影
门控 = 唾手可得的提升。命名按门控激活函数：SwiGLU（LLaMA/PaLM 系）、GeGLU（Google 系 Gemma/T5）。
2/3 缩放：GLU 多一个矩阵 V（三矩阵），为保持参数量把前馈维 ×2/3（Noam Shazeer）→ GLU 模型常见 ~2.67
并行 vs 串行层：并行已过气
并行 GPT-J / PaLM：注意力 + MLP 输出相加回残差流。可融合矩阵乘、共享 norm
串行 先注意力后 MLP。主流——串行优化够好，并行损失约一半"深度"
位置编码：RoPE 主导（2024 后）
注意力与位置无关（纯内积，可打乱顺序），故需位置编码。
正弦余弦（原版） → 绝对嵌入 → 相对嵌入（T5） → RoPE
RoPE：按位置旋转 Q/K 向量。内积对旋转不变 → 只依赖相对位置、无绝对位置交叉项
高维：D 维向量切成 2D 对，每对不同频率 θ 旋转；低频捕长程、高频捕相邻。在注意力级（Q、K）施加
— 超参数篇 —
超参数 Cheatsheet（都很"宽容"）
超参数 经验值 备注
前馈比 FFN_dim/D 4× GLU ×2/3≈2.67；LLaMA2 ≈3.5；T5 64× 是异类。Kaplan：1~10 平坦盆地
头数与头维 head_dim × n_heads = D 不成文规则，很宽容
深宽比 D / n_layers ≈100 深→流水线并行难；宽→张量并行易。但真正决定性能的是 FLOPs
词表大小 30k（单语）/ 100–200k（多语言） Google 偏大；随模型规模增大
正则化：反直觉——它其实在做优化
计算受限 LM 几乎不过拟合（单遍 SGD 记不住数据），理论上不需正则化。但——
weight decay 仍流行！证据显示它更像优化干预（与 LR 衰减协同收敛更优），而非控过拟合
dropout 逐渐被弃——与优化过程不兼容
— 稳定性 & 注意力篇 —
训练稳定性：花了百万美元不能崩
softmax 是危险区（指数 + 除法）。模型里有两个：输出端 + 注意力端。
Z-loss（输出端）
惩罚 (log Z)² 使归一化因子≈1。Jacob Devlin 2014；Baichuan 首个开源采用，后 DCLM、Olmo 跟进
QK Norm（注意力端）
Q·K^T 前对 Q、K 各加归一化，softmax 输入尺度≈1。源自多模态，现标准且不损性能
Logit 软上限（Gemma）
tanh 硬限制 logits。安全但牺牲表达力，NVIDIA 消融显示略降性能
为何重要
训练中途 loss 暴涨/梯度尖峰可能无法恢复，浪费百万美元算力
注意力干预：为推理效率与长上下文
MQA 所有头共享一组 K/V，省内存但损表达力
GQA 减少 K/V 头、保留 Q 头。推理低成本 + 性能近全多头 → 当前主流
KV cache：自回归推理复用历史 K/V，但算术强度变差（N/D 项，内存受限）
滑动窗口混合：全注意力 + 局部交替。Command A 每 4 层 1 全局+3 局部；Llama4/Gemma4/Olmo3 同思路；Qwen3.5 用门控 DeltaNet（SSM）替代局部层
当前最活跃的演进方向 = 长上下文注意力混合架构

★ 骨架：pre-norm + RMSNorm + 去偏置 + SwiGLU + RoPE + GQA

★ 超参：4×/2.67 前馈 + ~100 深宽比 + 头数=D

★ 稳定：按需加 Z-loss / QK Norm

★ 长上下文：加滑动窗口混合

★ 把精力留给数据和规模，而不是花式改架构
