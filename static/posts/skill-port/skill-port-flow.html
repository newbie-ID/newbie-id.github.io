skill-port
把 Agent Skill 打包成可移植目录包 · 跨机器 / 跨 harness 还原
它只做三件事
2025–26 年 skill 已收敛成开放标准（SKILL.md + .agents/skills/），所以 skill-port 不做格式翻译，只做：打包 / 跨机还原 / 依赖重装。
Phase 1 · pack（打包 / 备份 / 迁出）
扫描已装 skill ➞ 解析 SKILL.md ➞ 复制 payload
排除运行态 ➞ 识别依赖 & 工具面 ➞ 产出 .skill/ 包
Phase 2 · restore（还原 / 安装 / 迁入）
读包 ➞ 工具面硬拦
缺能力即中止 ➞ 同名冲突询问 ➞ 按目录映射复制 ➞ 依赖核查 + 提示重装
三个关键决策
两张表 HARNESSES（发现目录）+ CAPABILITIES（工具面能力）= 全部适配。加新 harness 只改 adapters.py 一行。
依赖不内联 二进制 / 下游 skill / MCP 只声明进 manifest，目标机由 setup.sh 重装。运行态（bin/models/library）整个排除 → 5.5 GB → 71.8 KB。
硬拦 ≠ 静默 工具面不匹配立即中止交人 review；同名冲突询问；默认不自动跑 setup。
包结构
# <name>.skill/ = 唯一真相源 + 标准 skill 形态
manifest.json   # 元信息 / 来源 / 依赖 / 工具面 / provisioning
payload/       # SKILL.md + scripts + references,原样内联
