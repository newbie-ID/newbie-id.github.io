什么是 BERT？
BERT 全称 Bidirectional Encoder Representations from Transformers，是 Google 于 2018 年发布的 预训练语言模型。 其核心思想：利用大规模无标注语料进行预训练，再用少量标注数据微调，在 11 项 NLP 任务上全面 SOTA。
核心架构：双向 Transformer 编码器
GPT 单向 Transformer Decoder，从左到右逐 token 生成，无法感知右侧上下文
BERT 双向 Transformer Encoder，每个 token 同时感知左右两侧上下文，理解更深
两个预训练任务
MLM (Masked Language Model) — 掩码语言模型
随机掩码 15% 的 token，让模型预测被掩码的词汇
80% 替换为 [MASK]，10% 替换为随机词，10% 保持原词
训练目标：仅在被掩码位置计算预测损失，模型学到双向上下文理解
NSP (Next Sentence Prediction) — 下一句预测
判断句子 B 是否是句子 A 的 真实下一句（二分类）
训练时 50% 为真实相邻句，50% 为随机选取的不相邻句
训练目标：学习句子间的 关系与连贯性，增强句子级语义理解

输入表示：三种 Embedding 相加
Token Embedding + Segment Embedding + Position Embedding = BERT 输入向量
Segment Embedding：区分句子 A 和句子 B（用于 NSP 任务）
Position Embedding：学习位置信息，支持变长序列

历史地位与影响
核心贡献

★ 开创了 NLP 预训练范式，结束了 ELMo/GPT 分庭抗礼的局面

★ 在 11 项 NLP 任务 上全面刷新 SOTA 纪录

★ 证明了 "预训练 + 微调" 范式的有效性

★ 启发了 RoBERTa、ALBERT、DistilBERT 等后续工作

★ 成为 现代 NLP 的基础架构，工业界广泛应用

BERT ➞ RoBERTa ➞ ALBERT ➞ DistilBERT ➞ Modern NLP
